Esta pasta foi esvaziada de propósito.

As imagens de cada produto serão associadas depois, via app desktop
e banco de dados (campo "image" retornado pela API). Enquanto um
produto não tiver uma imagem definida, o site mostra automaticamente
um placeholder "Sem imagem" no lugar da foto — não é necessário
adicionar nada aqui manualmente.

Se quiser guardar imagens localmente (em vez de usar uma URL externa
vinda da API), pode salvá-las nesta pasta e apontar o campo "image"
do produto para "assets/products/nome-do-arquivo.jpg".
